FAQ — question marker

Comparing the current accent-circle badge with lighter alternatives. Same content in every block so the difference is purely the marker treatment.

Current

Solid accent circle + chevron

A 24×24 pink-filled circle with a navy chevron-down sits before each question. The strongest contrast — and the heaviest visually.
